## 本地数据全量审计命令

在求解数据导出结束后，从项目根目录运行。使用项目已安装的 esbuild，不需要额外安装 `tsx`：

```powershell
node node_modules/esbuild/bin/esbuild scripts/audit-local-data.ts --bundle --platform=node --format=esm --outfile=.runtime/audit-local-data.mjs
node .runtime/audit-local-data.mjs
```

默认原子更新私有的 `data/private/solver-audits/validation-and-coverage.json`。可用 `--no-write` 只验证和输出摘要，或使用 `--root "D:/projects/GTO_Reminder"` 验证另一份工作区；`--output "路径.json"` 指定审计文件。工具只读取本机数据，不联网、不重新求解，不修改策略文件。

审计复用应用实际的 v1/v2 校验器、经过摘要审核的参考资料读取器、模型分片规则和 434 个标准类别统计。它逐项核对合法行动历史、169 类手牌显式状态、条件频率、跨片 ID/历史重复、计算快照与最终差距的对应关系；受限模型还核对引擎补丁、源码、二进制与概率模型身份元数据。所有输入文件记录大小和 SHA-256，`missing`、`unreachable`、参考图未绘制/不可读状态分别保留。v1 快捷节点与 v2 决策重叠，不相加。

审计使用与本地 API 相同的恢复锁/持久代际屏障，并在结束前重新核对输入清单和文件指纹。恢复正在进行、扫描期间数据变化、任意文件验证失败时，会退出并保留上一份成功审计。该验证确认结构、来源声明的一致性和场景可读性；不独立证明求解精度，也不把 434 个标准类别等同于完整 NLHE 游戏树。

