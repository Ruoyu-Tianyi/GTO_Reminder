# 收藏与全压应对分析

适用范围：6–9 人、100 BB 现金桌的现有翻前工作台。收藏不保存策略频率；条件 EV 不补写 GTO 动作频率。

## 保存和换电脑复习

在“参考范围图”“完整行动历史”或“快捷范围查询”点击“收藏当前场景”，再打开“我的收藏”。每条收藏保存手牌、位置和查询条件；完整历史还保存按顺序发生的每一步行动及各座位筹码。

收藏同时保留当时的来源信息，包括计算模型、迭代、日期、精度和研究状态；参考图记录 PDF 指纹、页码、动作尺寸以及是否为 8→7 座位投影。打开收藏时，来源信息不同或不存在，会保留原查询并显示缺失，不自动改用演示、其他模型或新快照。主动选择来源后才能查看新来源的频率。来源身份比较的是文件声明的元数据，不能识别“频率被手动改变，但所有元数据保持相同”的篡改。

收藏自动保存在当前浏览器。换电脑前，在“我的收藏”点击“导出收藏”，在另一台电脑“导入收藏”。导入按完整查询和来源去重，保留已有收藏；最多 200 条，文件上限 2 MB。删除后可撤销最近一次删除。浏览器存储不可用或原记录版本不兼容时，界面仍保留本次内存收藏并提示导出，不覆盖损坏或未知版本的记录。

收藏文件不包含手牌频率、历史到达权重、原 PDF 或求解结果。另一台电脑还需恢复相应私人数据，见[数据迁移](DATA_MIGRATION.md)。临时上传的策略仍只存在于当前页面，刷新后应重新导入，或放到本机 `data/private/`。

## 全压跟注的条件 EV

“完整行动历史”中，当只剩一位已经全压的对手，且当前跟注会结束下注、没有未跟注退款或边池时，出现“全压应对 · 条件 EV 估算”。可以取消选择模型，然后用“面对 5-Bet All-in”示例构建合法历史；示例只定义行动，不代表推荐打法。

1. 选择假设对手范围：均匀随机、启发式前 10% / 20% / 40%，或自定义手牌类别权重。范围不会根据全压动作自动推断。
2. 明确选择无抽水，或输入抽水比例和 BB 封顶。默认抽水未知时不计算 EV。文字抽水标签不自动变成数值规则。
3. 计算单手，或全部 169 类。每手可选 1,000、5,000、20,000 或 100,000 次采样，后台计算可随时停止。
4. 查看摊牌份额、跟注增量 EV、盈亏平衡份额和 95% 采样区间。仅当 EV 区间完全高于或低于零时给出相应倾向；跨零时显示不确定。

弃牌基准为当前决策的增量 `0 BB`，此前投入是沉没成本。跟注 EV 为：

```text
EV(call) = 摊牌底池份额 × (跟注后底池 − 抽水) − 还需跟注金额
盈亏平衡份额 = 还需跟注金额 / (跟注后底池 − 抽水)
```

模拟发出相容的实体底牌和公共牌，排除同一牌重复出现，单挑平局平分底池。自定义 JSON 中 `{"AA":1,"AKs":0.5}` 表示 AA 每个具体组合的相对权重为 1，AKs 为 0.5，未列出的类别权重为零；对子、同花、非同花各自的组合数由计算器处理。

95% 区间仅描述单手采样误差，不涵盖对手范围、抽水规则的误差，也不是同时保证 169 类手牌的联合区间。计算忽略已弃牌玩家未知底牌和其范围带来的条件信息。增加样本不能修正错误的范围假设。全压跟注会发出公共牌，因此“未见翻牌不抽水”不使该已跟注底池免抽水。

“导出本次计算”包含原始行动历史、范围、抽水、采样请求、胜率结果、EV 和限制说明。改变历史、范围、样本数或抽水会停止计算并清除旧结果，防止把前一个场景的结果显示到新场景。这些结果不写入策略库、不生成混频，也不计入标准场景的策略覆盖率。
